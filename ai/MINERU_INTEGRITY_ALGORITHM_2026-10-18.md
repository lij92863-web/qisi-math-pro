# MinerU 内容及归属算法

## 1. 问题模型

OCR 块是版面单元，不保证等于题目、答案或一个字段。一个块可含多题，一个题可跨多块和多页。按块边界或题号集合直接建立归属没有充分依据；把派生 ID 当作已有 ID、转换时只保留部分字段，会让已经识别出的内容再次丢失。

输入为有序来源块 B，每块有唯一 ID、类型、文本/资源及源项下标。输出分三层：不可变来源证据、带来源范围的片段、经过序列验证的题目绑定。绝不根据题意计算答案或用语义相似度配对。

## 2. 内容保留

原始 content_list 完整保存为 evidence.items。显示层跳过 page_number 但保留其来源；未知类型保留并报告，非法页码报错，不能默认为第一页。

图片/表格 caption、footnote 规范化为独立文本块，以 parentId 指向资源块，origin 指向原始字段及数组下标。它们不是推断生成的文字。基础块编号只由原始项顺序决定，插入 caption 不改变后续基础块 ID。模型 payload 传播 parentId，显示组装使用同一批文本块。

## 3. 边界文法及限制

先扫描数学定界区域 $...$、$$...$$、\\(...\\)、\\[...\\]，区域内数字不能作为题号。原字符不改动，掩码与原文等长，所有位置均为 UTF-16 半开区间。

编号支持正整数及全角数字、点号/顿号，或编号直接连接【答案/解析/详解】等明确标签。小数的小数点、公式中的数字不构成边界。

块首普通题号可形成题目候选。块内部题号不能仅因属于 expected 集合就切分；必须具有明确支持材料结构（答案标签、独立选项答案、以(1)开始且有后续分问/解析标签佐证的答案组，或纯数值/公式头紧接解析标签），并通过整段编号验证。独立行上的不明确预期编号产生 ambiguity，阻断绑定；句内“最小值为 2.”等数值结论不因等于预期题号就成为边界。头部明确的答案标记与标号采用同一文法，避免多套正则不一致。

这份文法是可检查的输入假设，不能从任意文本证明真实出题意图。如果题内步骤与顶层答案使用完全相同的排版及标记，纯文本无法保证区分；此类材料需要额外来源证据/人工确认，不能以“覆盖率更高”为依据选择归属。测试必须包含预期题号恰好出现在普通步骤内的反例。

章节边界不能只取首个重启题号：明确的“《标题》参考答案”属于章节头；已确认重启时，向前只吸收紧邻的结构化“题号/答案”表及其 parent 附属文字、完整章节头或“《标题》参考”拆行头，放入支持材料 preamble。回溯不能越过前一题题号，不吸收普通续段。答案表单独出现不证明进入答案章节。

## 4. 片段代数与引用完整性

切分区间 [0,c1),[c1,c2),...,[ck,L) 完整覆盖原字符串，不 trim、不改写正文。片段 origin={blockId,range:[start,end],...}；ID 由来源块 ID 与绝对范围生成。重复切分仍指向同一原块范围。

输出同时交付 blocksById，包含原始块和全部派生片段。每个公开引用必须在索引中存在；每个派生片段必须等于来源文本相应范围。再次切分派生块时传入 sourceRegistry，不能只交片段却丢掉原始来源。不同文件先加明确角色命名空间，避免 p1b0 相互覆盖，原文件身份仍在 origin.sourceId 中。

## 5. 序列和绑定

先验证全部题目与支持材料的题号唯一、严格递增、在声明集合内且无缺失，再建立 Map。异常时不允许“最后一个重复项覆盖前一个”。无显式 expected 时仅对观察到的最小/最大题号之间检查连续性，不臆造卷首/卷尾。

assemble 必须消费验证状态；不把 issues 当作可忽略备注。支持材料有序列/边界/来源异常时，答案与解析引用均为空，候选内容保留在 segmentation/index 中。coverage.matched 表示相同编号的数量，coverage.paired 仅统计实际允许绑定的题目。

答案只读取明确的答案头或该题内一致的“故选”声明，不能计算/推导。答案表与显式声明冲突时保留冲突证据并阻断该题支持绑定。题目-only 没有支持材料不算 OCR 失败。

答案表解析也区分“未出现”和“出现但非法”。题号只能是整个单元格表示的正整数，不能删去字符把“1-2”变成“12”；行列不齐、空答案、重复题号或跨表冲突报错。矩形表末尾成对空单元格可忽略，不能将单边空缺混作填充。

## 6. 可验证性质

1. 内容守恒：来源完整保留；片段不重叠且按顺序拼接精确还原原文。
2. 引用闭合：公开 ID 可解析；片段来源和范围有效。
3. 不覆盖：重复块/题号进入异常结果，不构造覆盖后的有效绑定。
4. 不跨文件污染：配对双方 ID 命名空间分离，来源身份保留。
5. 不推断题号：输出题号均来自数学区域外的明确源标记，不按期望列表造题。
6. 异常不绑定：任意序列/来源异常不能产生已确认答案或解析。

证明边界：这些性质约束程序变换和准入；不宣称 OCR 字符正确或文法之外的题意正确。

算法对总文本长度 T、块数 B、边界数 C 做线性扫描、集合验证及索引构建，目标 O(T+B+C)；不做全对全语义比较。范围切片的总输出字符量为 O(T)。附属块数量与原始 caption/footnote 项数线性相关。

## 7. 验证计划

合成测试覆盖任意题号平移、两题/三题同块、跨页、无点号答案标签、全角编号、题内步骤、小数、公式中的伪题号、重复/倒序/缺号、同名跨文件块、caption/footnote、未知类型、片段拼回及二次切分。真实离线结果检查六份来源、33个客观答案、河北第18题归属、深圳第15/16题索引、完整题目/答案12题配对及所有附属文字保留。无需重新 OCR。
