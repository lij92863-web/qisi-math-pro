## 0. 先说结论（给没时间看全文的人）

1. 老师要的不是"排版软件"，是**"从题库里捞几道题，套一个像样版式，一键出 PDF"**。他能忍受只有 8 个可调项，忍不了填 LaTeX 源码。
2. 项目里已经有 60% 的东西了：`EXAM_LAYOUT_PRESETS` 两个预设、20+ 版式字段、`window.print()` 打印管线、KaTeX 本地字体。**讲义不是新功能，是给现有"试卷排版"加第三种预设 + 加"文字区块" + 换一套更说人话的模板面板。**【实测：`qisi-config.js:117`、`app.js:4523-4790`、`main.html:1437-1498`】
3. 公式保真的最硬结论：**不要导出 Word**。Word 路线要么公式变图片、要么字体缺失变方框，这是全网一致的老问题。走 **HTML + KaTeX → Chromium 打印 PDF**，字体全部嵌入，跨机器不乱码。**【实测：7 页 PDF，`pdffonts` 显示 SimSun/SimHei/KaTeX 全部 `emb=yes`】**
4. 页面页码"第 X 页 共 Y 页"**能实现**：Chrome 131+ 起支持 `@page` 边距框；我用 Playwright 实测 7 页，每页页脚正确输出"第 N 页 / 共 7 页"。**【实测】**
5. 现在这条打印路径有一个**必须修的坑**：公式渲染失败时会降级成红色小字继续导出，属于"静默放行"。讲义上线前必须改成"先检查、再导出"。**【实测：`app.js:4547-4560`，`strict:'ignore'` + catch 返回红字】**

### 1.4 一份讲义的解剖（用来定默认值）

【查到】某校《高中数学学案制作格式标准》：**B5 纸（25.7×18.2cm）**，上下边距 2.54cm、左右 3.17cm；标题"小四宋体加粗居中"，小标题"五号宋体加粗"，正文"五号宋体"；区块名就是**【课标要求】【知识要点】【范例剖析】【双基测评】【课后作业】**。<http://www.bodocs.net/doc/4f4316927.html>

【查到】另一校导学案细则：当堂检测 **3-5 题**，"题宜精不宜多"；课后作业 **8 题左右**，分【必做】【选做】。<https://wenku.baidu.com/view/0a4d92738e9951e79b892746.html>

【查到】上海"学习任务单"实例：学习目标 2 条、课前任务 2 条、课上 4 个活动（含例 1/例 2/例 3 + 变式）、课堂练习、评价任务表。<https://smileresource.shec.edu.cn/...>

**汇总成一份"典型讲义"的样子（我的归纳）**：

```
标题（章节名）           ← 必有
班级/姓名/日期栏          ← 学生版必有
学习目标（2-3 条）        ← 学案有，作业没有
知识梳理/知识要点（留空给学生填）← 学案核心，题库里没有！
例题（2-4 道，带解析）     ← 来自题库
变式/巩固（2-4 道）        ← 来自题库
当堂检测（3-5 题）         ← 来自题库
课后作业（5-8 题，可分层）  ← 来自题库
页脚（页码 / 日期 / 寄语）  ← 可选
```

**关键洞察**：题库只提供"题"。而一份学案里**"知识梳理"这块是老师自己写的文字**，题库里根本没有。所以讲义功能必须支持 **"插入一段自由文字"**，否则做出来的东西永远只是"一份卷子"，不是"学案"。这一点现有"试卷排版"完全没有。

**题量与频次**：
- 单份：学案 1-2 页、8-15 题；作业 1 页、5-8 题；复习提纲 2-4 页。【查到题量区间 + 推断页数】
- 频次：高中数学约 20 个教学周，每周 1-2 份课时学案 → **20-40 份/学期**。【推断，无统计数据】
- 单份耗时：1-2 小时（含找题、排版、校对）。【查到】

## 2. 公式保真：技术路线（本项目的命门）

### 2.1 KaTeX vs MathJax

| 维度 | KaTeX | MathJax | 依据 |
|---|---|---|---|
| 体积 | 核心 JS ~277KB + CSS 24KB + 字体；全量约 350KB | 常见配置 200KB~600KB+ | 【查到】<https://finance.biggo.com/news/202511040733_KaTeX_MathJax_Web_Rendering_Comparison> |
| 速度 | 同步渲染，约 10-30ms/公式，无重排 | 更重，异步 | 【查到】<https://deepwiki.com/remarkjs/remark-math/4.2-renderer-comparison> |
| LaTeX 覆盖 | 高中数学足够；不支持 `\label/\eqref`、`\ce`、`align` 环境（要 `aligned`） | 更全 | 【实测，见 2.5 表】 |
| 中文混排 | 支持，`\text{当}` 正常 | 支持 | 【实测】 |
| 离线 | 完全离线（CSS+字体本地） | 完全离线，但要配字体路径 | 【查到+实测】 |

**结论**：继续用 KaTeX。项目已内置 `vendor/katex` 0.16.47，`katex.min.js` 272,537 字节，`fonts/` 齐全，`katex.min.css` 引用相对路径 `fonts/*.woff2`。**【实测】**换 MathJax 只有坏处（体积翻倍、要改现有渲染调用）。

### 2.2 老师题源里公式长什么样

本项目已经处理了绝大多数形态（这是一笔资产，别重造）：

| 形态 | 现状 | 位置 |
|---|---|---|
| `$...$` / `$$...$$` / `\(...\)` / `\[...\]` | 已支持，含"未闭合"检测 | 【实测】`qisi-utils.js:75-140` `tokenizeLatexSource` |
| `[[IMAGE:...]]` / `[[FORMULA_IMAGE:...]]` 图片公式 | 打印时特殊处理 | 【实测】`app.js:4540-4545` |
| Word OMML | Pandoc 路线成功率约 95%（1000 条样本），复杂结构会挂 | 【查到】<https://blog.csdn.net/weixin_33146151/article/details/167052486>；另有报告称论文场景 60-70% 需人工修 <https://thelatexlab.com/blog/convert-word-to-latex-equations/> |
| MathType (MTEF/OLE) | 项目已有 `qisi-docx-mtef-reader.js`、`qisi-docx-ole-reader.js` | 【实测】 |
| 纯文本上下标（`x^2`、`a_n`） | 不在 `$` 内就不会被渲染，会原样显示 | 【实测，推断为常见漏网】 |

**各类占比：不编造。** 正确做法是上线前用一条脚本统计题库：扫 `questions.stem/answer/solution/options`，分别统计"含 `$`""含 `\(`""含 `[[FORMULA_IMAGE`""一个都没有"的题数。这个数出来再决定门禁的松紧。

### 2.3 导出路线对比（核心权衡）

| 路线 | 公式保真 | 联网 | 装软件 | 老师能否二次编辑 | 复杂度 | 结论 |
|---|---|---|---|---|---|---|
| **A. 浏览器打印 / `window.print()` → 另存 PDF** | 高（矢量、可选中） | 否 | 否 | 不能改 PDF，但能回系统改 | 低（已有） | **主路线** |
| **B. 本地服务 Playwright → PDF** | 高，且与预览 100% 同源 | 否 | 否（Chromium 已在 devDeps） | 同上 | 中 | **备选/增强** |
| C. HTML → DOCX（docx/mammoth/pandoc） | 中低：公式退化为图片或 OMML，字体易丢 | 否 | 否 | 能改 | 高 | 不做 |
| D. 直接 LaTeX → PDF（ctexart） | 最高 | 否 | **要装 TeX Live（GB 级）** | 不能 | 高 | 不做 |
| E. Typst → PDF | 很高 | 首次装包需网 | 要装 Typst | 不能 | 高 | 不做 |

**为什么不是 C（Word）**：Word 里公式要么是 OMML（可编辑但字体依赖 Cambria Math），要么被降级成图片（糊、不可检索）。这两个坑在上面 4 条来源里反复出现。老师真正的诉求是"打印出来好看"，不是"我要改 PDF 里的字"。

**主路线 A 的具体形态**（已存在，改动最小）：
`app.js:4700-4790` 已经会：新窗口 → 注入 KaTeX CSS → 等图片和字体 ready → 启用"打印 / 另存为 PDF"按钮 → `window.print()`。`@page { size:A4; margin:18mm 16mm }`，题目 `break-inside:avoid`。

**备选 B 的价值**：只有两个——(1) 自动页码页脚更稳；(2) 不用老师手动点"另存为 PDF"。代价是多一个本地接口 + 一次进程启动（约 1-2 秒）。

### 2.4 我做的实测（这节是硬证据）

在本机用仓库自带 Playwright Chromium（m149）+ 仓库自带 KaTeX 0.16.47 生成 A4 讲义样张，7 页，然后：

```
pdfinfo   → Pages: 7
pdftotext → 第 1 页 / 共 7 页 … 第 7 页 / 共 7 页   （每页都在）
pdffonts  → SimSun        emb=yes
            SimHei        emb=yes
            KaTeX_Math-Italic / KaTeX_Main-Regular / KaTeX_Size2/Size3  emb=yes
pdftotext → 公式提取为 f (x) = x3 − 3x2 + 2, ∫, lim, sin α … 可选中、可搜索
```

三条结论：
1. **`@page` 的 `@bottom-center { content: "第 " counter(page) " 页 / 共 " counter(pages) " 页" }` 在 Chromium 里真的能用**（此前很多教程说"不支持、要用 headerTemplate"，那是 Chrome 131 之前的旧知识）。**【实测】** 参考背景：<https://dev.to/accreditly/can-i-use-it-in-a-pdf-css-support-across-html-to-pdf-engines-4n53>
2. **字体全部嵌入**，换电脑不会出现方框。
3. **`break-inside:avoid` 有效**：260px 高的作答留白块整体挪到下一页，没有被切一半。**【实测】**

⚠️ 但 `window.print()`（老师手动在打印对话框点保存）与 Playwright 的 `page.pdf()` **不是同一条命令**。前者是否渲染 `@page` 边距框，取决于本机 Chrome 版本（131+ 可以）。**【推断，需在目标机器上实测一次】** 兜底方案：打印窗口里不承诺页码，或改用路线 B。

### 2.5 "不乱码"的判定标准与自动门禁

**判定标准（三层，从便宜到贵）**

| 层 | 检查什么 | 手段 | 成本 |
|---|---|---|---|
| L1 分隔符 | `$` 不成对、`\[` 没闭合 | 现成的 `tokenizeLatexSource().issues` | 0 |
| L2 可编译 | KaTeX 抛不抛错 | `renderToString(tex, { throwOnError:true })` | 1ms/公式 |
| L3 有隐患但没报错 | 全角空格、`㎡`、未知符号、`\includegraphics` 这类"能过但会难看/为空" | `strict` 传**函数**，收集 `code`+`token.loc` | 1ms/公式 |

L3 是本次调研挖到的一个好用技巧：KaTeX 的 `strict` 可以传函数，它会把每个"本应警告"的问题回调给你，带**精确字符位置**。我实测：

```
输入 a　b 5㎡ 30°
回调 → unicodeTextInMathMode @ offset 1（全角空格）
       unknownSymbol        @ offset 5（㎡）
```
**【实测】** 这意味着报错可以精确到"第 3 题第 12 个字"，老师点一下就能定位，而不是甩一句"公式有误"。

**我实测的 KaTeX 行为表（高中数学相关）**

| 写法 | 结果 | 说明 |
|---|---|---|
| `\frac{a}{b}`、`\dfrac`、`\sqrt`、`\int_0^1`、`\lim_{n\to\infty}` | ✅ | 正常 |
| `\begin{aligned}...\end{aligned}` | ✅ | 多行推导可以 |
| `\begin{align}...\end{align}`（行内） | ❌ | 只能 display mode；老师从 Word 粘过来常见 |
| `\begin{cases}`、`\begin{pmatrix}` | ✅ | 分段函数、矩阵没问题 |
| `\text{当}x>0\text{时}` | ✅ | 中文混排 OK |
| 裸中文（`当x>0时` 不在 `$` 内） | ✅ 原样显示 | 不进公式，反而最安全 |
| `\label{}`、`\tag{}`（行内） | ❌ | 从论文/Word 带过来的编号 |
| `\ce{H2SO4}` | ❌ | 未加载 mhchem；高中数学用不上 |
| `\includegraphics{...}` | ⚠️ **不报错但渲染为空/占位** | **最危险**：静默失败 |
| 全角括号 `（`、全角逗号 | ✅ 但字距怪 | 建议提示 |
| `㎡`、`\foo{}`、`\frac{1}{2`（缺括号） | ❌/⚠️ | 前两个报错，缺括号报错 |

**失败时 fail-closed 还是降级？我的建议是"分级"**：

- **阻断**（不允许导出）：L1 未闭合 + L2 抛错 → 弹窗列出"第 3、7 题"，给两个按钮：`去改这几道题` / `仍然导出（这几题的公式会显示成原文）`。
  → 即 **默认 fail-closed，但给一次显式的、说明后果的放行**。理由：老师可能就想先打出来看看，硬拦会让人放弃使用。
- **提示不阻断**：L3 的 `unicodeTextInMathMode` / `unknownSymbol` → 顶部黄条"第 5 题有 2 个符号可能显示不正常"，可忽略。
- **绝不**像现在这样：打一行 `console.warn` 然后页面里出现红字 `[公式语法错误]`，老师完全不知道，直到印出来才发现。**【实测：`app.js:4555`】**

## 3. 模板系统设计

### 3.1 老师真正在意的，砍到 8 项

先看现在暴露了多少：`EXAM_LAYOUT_PRESETS` 单个预设 **21 个字段**（`qisi-config.js:121`），界面还有"高级源码编辑器"直接编辑 `ctexart` LaTeX。**【实测】**这对非程序员是灾难。

按"老师改一次就会骂人 / 改了真的有用"筛选，只留 8 项：

| # | 可调项 | 为什么留 | 控件 |
|---|---|---|---|
| 1 | **纸张** A4 / B5 / A3 | B5 是国内学案常见规格【查到】 | 分段按钮（3 个） |
| 2 | **正文字号** 五号 / 小四 | 直接影响一页能放几题 | 分段按钮（2 个） |
| 3 | **字体** 宋体 / 楷体 | 宋体正式、楷体亲和；只给两种，别给字体列表 | 分段按钮 |
| 4 | **行距** 紧凑 / 正常 / 宽松 | 直接决定"挤不挤"，是老师调得最多的 | 三档滑块 |
| 5 | **每题留白** 无 / 1 行 / 3 行 / 5 行 | Kuta 的"Easy Spacing"验证过这是刚需 | 四档按钮 |
| 6 | **是否显示解析** 无 / 题后 / 全放最后 | 教师版/学生版的分水岭 | 三选一 |
| 7 | **页眉文字 + 页脚** 开关（页码） | 学校要求 | 输入框 + 开关 |
| 8 | **主色**（标题/分割线） | "好看"的主要来源；给 6 个预设色，不给取色器 | 色板 6 选 1 |

**明确砍掉**（老师不会调，调了必出问题）：
- 公式字体、公式字号 → **跟随正文自动，禁止单独设置**。理由见 WPS 社区那条吐槽：公式字体一改就散。**【查到】**
- 题号格式（`1.` vs `一、`）→ 按题型自动，中文大题号 + 阿拉伯小题号是行业惯例。
- 页边距（mm 级）→ 由纸张预设决定。
- 双栏 / 分栏 → MVP 不做（双栏 + 公式 = 溢出，来源已证）。
- 任何 CSS / LaTeX 源码输入框。

### 3.2 "专属模板"两条路

| | ① 表单式（勾选+下拉） | ② 照着一张讲义自动提取样式 |
|---|---|---|
| 老师操作 | 调 8 个开关 → 起名 → 保存 | 上传一张 PDF/照片 → 系统猜字体字号 |
| 可靠性 | 100%（结构可控） | 低：字体识别、字号换算、栏数判断都会错 |
| 覆盖"我想要那个样子" | 只能覆盖 80% | 理论上 100% |
| 工期 | 2-3 天 | 2-3 周，且要做到"不忽悠"很难 |

**取舍：做①，把②降级成"照葫芦画瓢"的半自动**：
老师在预览页点"我想要更像这张"，系统只提取 **3 个最稳的量**：纸张比例（A4/B5）、大致字号（按字高/页高比）、是否双栏。其余仍回到表单项让老师确认。
→ 承诺的是"帮你猜个七成"，不是"完美复刻"。这样不会翻车，也不会让老师觉得被骗。

## 4. 交互与界面

### 4.1 四步主流程（中文按钮文案）

> 实施建议：**不要新做一套四步向导**。现有"题库 → 试卷篮 → 试卷排版 → 打印"就是这四步，只是第 2、3 步文案不是人话。改成：

**第 1 步「挑题」**
- 左侧题库列表（已有筛选），每题右侧一个按钮：**「放进讲义」**
- 顶部悬浮条：`讲义里已有 6 道题` ＋ **「去看看」**
- 抽屉里每题右侧两个小按钮：**「上移」「去掉」**
- 空状态文案：「还没选题。在左边勾几道，或者用上面的『按知识点找题』。」

**第 2 步「排顺序」（可并入第 3 步右侧面板）**
- 整行拖拽（已有 `draggingExamQuestionId`）
- 每题展开一行小设置：`留白：无 / 1 行 / 3 行`、`显示解析` 开关
- 顶部两个按钮：**「加一段文字」**（插入知识梳理/小结）、**「按题型分组」**

**第 3 步「选版式」**
- 三张**大卡片缩略图**（不是下拉框）：
  - `课时学案`（标题 + 姓名栏 + 知识梳理 + 例题 + 当堂检测）
  - `课后作业`（标题 + 题目 + 留白，无知识梳理）
  - `复习提纲`（标题 + 分组标题 + 题目，紧凑）
- 卡片下方一行：**「微调」**→ 展开 8 个控件（见 3.1），每个控件右侧一个 `?` 说明一句人话
- 底部：**「存成我的模板」**（弹一个输入框，默认名"我的学案 1"）
- 右侧常驻预览。

**第 4 步「导出」**
- 大按钮：**「导出 PDF（推荐）」**；次按钮：**「直接打印」**
- 导出前自动跑检查，如果没问题：正常导出。
- 如果有问题：抽屉从右侧滑出，标题 **「有 2 道题的公式可能印不出来」**，列题号 + 原文片段，两个按钮：**「去改这两道题」** / **「先导出来看看」**。

**文案禁用词**：配置、参数、渲染、样式表、编译、LaTeX、实例化。老师的话是"字号""留白""版式""导出来"。

### 4.2 右侧实时预览：必要，但要限流

- **必要**：老师的核心焦虑是"印出来会不会乱"。没有预览，他不敢点导出。
- **代价**：每改一次字号就重排 15 道题 + 重渲染几十个 KaTeX 公式，低配笔记本会卡。
- **做法**：
  1. 预览用**缩略 A4 画布**（`transform: scale(0.45)`），不是全尺寸。
  2. 输入类（标题文字）→ `debounce 200ms`；选择类（字号/留白）→ 立即。
  3. **预览与导出共用同一段 HTML 生成函数**（现在的 `buildPrintContent` 已经是这样，别分裂成两套）。
  4. 预览只渲染当前页附近（题目多时先渲染前 2 页 + "共 N 页"）。
- **反面案例**：现有"模板视图"的"高级源码编辑器"——黑底代码框，老师看不懂，还把 `{{EXAM_TITLE}}` 这种占位符怼在右上角。**建议直接隐藏，或折叠进"高级（不推荐）"。**【实测：`main.html:1518-1570` 模板视图】

### 4.3 学案 / 试卷 / 作业 / 复习提纲：做成预设，不做成四种产品

- **做 3 个预设**（学案 / 作业 / 复习提纲），因为它们的差别是**结构差别**（有没有知识梳理、留白多少、是否分组），不是"另一个功能"。
- **允许老师在此基础上加减区块**（`blocks` 数组），但**不给空白画布**。空白画布 = 让老师自己设计 = 一定做得很难看。
- 试卷继续用现有两个预设（测验 / 高考），不合并。

### 4.4 常见误操作与防护

| 误操作 | 后果 | 防护 |
|---|---|---|
| 改模板把公式改坏 | 印出来是红字/空白 | 模板**只控制容器**，不进入题目 HTML；公式渲染参数写死，不给模板改 |
| 题量太多超页 | 打出 8 页，浪费纸 | 预览顶部常驻 `共 7 页`；超过 4 页弹提示 **「已经 7 页了，要不要把留白调小？」** |
| 导出时网络断了 | 图片挂了、KaTeX 没加载 | 全部本地资源；导出前检查 `document.fonts.ready` + 所有 `<img>.complete`（现有打印窗口已这么做，保留） |
| 图片缺失 | 空白框 | 导出前扫 `img` 的 `naturalWidth===0` → 列出来 |
| 改完没保存就关 | 白干 | 讲义草稿自动存 IndexedDB（沿用 `customTemplates`/新表），标题旁显示"已自动保存" |
| 公式里混全角空格 | 字距怪 | L3 提示，不阻断 |

## 5. 给这位老师的最小可行方案（MVP）

**一句话**：把现有"试卷排版"改造成"讲义排版"，加 3 个预设 + 1 个文字区块 + 1 道公式门禁。**不新建模块、不引入新依赖、不导出 Word。**

### 2-3 周排期（按可交付切片）

**第 1 周：门禁 + 数据结构（没有这个，后面都是沙子）**
- 新增 `handoutFormulaGate`：复用 `tokenizeLatexSource` + `katex.renderToString({throwOnError:true, strict:fn})`，输出 `{blocking:[{qid, field, message, offset}], warnings:[]}`。
- 把打印路径的红字降级改成"收集错误"，由调用方决定。
- 新增讲义模板 JSON（第 3.3 节），落到 IndexedDB 新表/新字段，不动老 `customTemplates`。
- **验收**：手动造 5 道坏题（缺 `$`、`\label`、`\ce`、空 `\includegraphics`、全角空格），门禁能准确列出题号与字段。

**第 2 周：模板面板 + 预览**
- 8 个控件（第 3.1 节），全部中文，卡片式预设。
- 预览复用现有 `buildPrintContent`，缩到 45%。
- 隐藏"高级源码编辑器"入口。
- **验收**：老师（真人）不看说明书，5 分钟内能改出一份"字号小四、留白 3 行、带页码"的讲义。

**第 3 周：3 个预设 + 文字区块 + 导出体验**
- 预设：课时学案 / 课后作业 / 复习提纲。
- `blocks`：支持"加一段文字"（纯文本 + 简单换行），插在题目之前/之后。
- 导出前检查清单（公式、图片、页数）。
- 打印窗口加一句提示：`在打印对话框里选"另存为 PDF"，纸张选 A4，边距选"默认"`。
- **验收**：从零到一份 2 页 PDF ≤ 3 分钟；公式在另一台电脑打开无异样。

### 明确不做

1. **不做 Word 导出**（公式必退化，见 1.3）。
2. **不做 LaTeX/TeX 编译**（要装 GB 级环境）。
3. **不做"上传一张讲义自动复刻模板"**（不可靠，先做半自动猜三项）。
4. **不做双栏/分栏**（公式溢出风险）。
5. **不做公式字体/字号独立设置**。
6. **不做在线分享、云端同步、多人协作**。
7. **不做 A/B/C 分层卷**（Kuta 有，我们用不上，且会拖长工期）。
8. **不做讲义内题目编辑**（要改题回题库改，保证单一数据源）。

## 6. 三个必须由老师本人拍板的问题

1. **你平时印的是 A4 还是 B5？双面还是单面？**
   → 决定默认纸张、页边距、以及"共几页"的提示阈值。这个猜错，第一版就废。

2. **学生版和教师版，你是"印两份"还是"一份里解析另起一页"？**
   → 决定 `answer.mode` 的默认值。现在系统里三种都有（只打印题目 / 题后新页答案 / 两份 PDF），必须选一个当默认，否则每次都要点。

3. **"知识梳理"那一块，你是想自己打字，还是想从题库里选"知识点条目"自动生成？**
   → 决定第 3 周是做"自由文字框"（便宜、够用），还是做"知识点库联动"（贵、容易做成半成品）。**我建议先做自由文字框**，但这是你的课，你定。
