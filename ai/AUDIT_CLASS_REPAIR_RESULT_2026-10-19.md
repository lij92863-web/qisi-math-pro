## 统一算法与模块职责

### 1. 支持证据以集合归并，不再把空字段当作“没有历史”

新增唯一业务模块 `qisi-support-evidence.js`，每条声明记录来源、引用、规范化文本范围及完整值。集合归并产生 `missing / unique / conflict`；冲突状态在新增自动证据下保持，字段值留空。相同值不因重复抽取产生冲突，不同完整值不再用子串或长度决定取舍。

解析器与 DOCX 字段契约共同消费这个状态。source port 先按文件角色选择字段，再走同一字段接口，删除原有绕过角色的冲突写入旁路。契约同时归并声明与实际待写值，避免字段值脱离其声明。

表格处理以原文行区间记录已消费内容，按相邻题号行/答案行解析每一张表。抑制的是同一范围的重复解释，不是所有同题号声明；损坏表不再令整份文档的其他声明消失。

### 2. 结构事实优先，纯文本不能证明的归属交审核

题目切块与支持区提取使用同一标题规则；编号展开使用原始 XML 段落序号，空段落不会挪动截止位置。括号题号走正常题号入口。

解析题头使用“题号 + 明确字段标签”的结构锚点；裸数字序列不足以区分题号与步骤，保留全文证据并停止自动挂接。完整 DOCX 已有生产者切好的题块时复用该身份，避免下游再从题干文本猜一次题号。删除第二条重复抽取解析的路径。

证据范围属于规范化支持文本坐标，不声称是 DOCX 原始字节偏移；原始文件仍由原导入链保留。

### 3. 候选与资产按身份处理

同源同号候选只在有效题干、有效字段兼容或有明确来源凭证等级可判定时合并。短题干同样参与身份比较。不能判定的不同字段保留完整候选；质量分只用于诊断，不再决定业务取值。字段值与凭证同步迁移，合并记录保存完整答案、解析及凭证。

去重把已提交题目及其图片作为不可变分区，可变题目与图片单独送入去重，再合回。传入副本避免去重函数重排污染原顺序。删除草稿的普通详情读取与列表保持不可见，原始行和图片仍可用于审计。

### 4. 选项词法与打印输入由单一实现提供

共享选项扫描器内部屏蔽数学区域，返回原文本位置；恢复完整 A–D 无标点选项行，兼容旧 DOCX。删除导入器内已失去用途的第二份数学屏蔽实现。

打印门禁与实际打印共同调用 `preparePrintSource` 和 `normalizeForKatex`，先做相同的裸公式规范化，再检查；只检查本次输出会使用的答案/解析字段。`app.js` 只保留委托与参数接线。

## 修复后的独立复审发现

复审不是仅重跑测试：重新检查了 parser → source port → contract → validator → review persistence 的状态消费，以及去重的空字段、字段凭证与资产边界。

1. **审核暂存与正式准入混淆。** 新增正常 UI 测试发现：底层冲突已保留，生产校验仍拒绝整批。修复 `qisi-import-validation-service.js`，逐条分类可审核错误，支持缺值与冲突并存；仅允许已清空、有所属来源和冲突证据的 DOCX 支持字段进入审核。正式准入策略未放宽。反例覆盖非空冲突、无声明、未归属来源、错误拒绝原因、题干拒绝。
2. **去重选项空值的口径不一致。** 去重前使用有效选项，合并时却用换行串判断非空，导致空数组/空字符串数组/只有 A. B. C. D. 的占位选项阻挡补全。统一有效选项键，覆盖两种 ID 排列与两种输入顺序；移除不可达的截断式冲突择优分支。
3. **答案表仍只找第一张，坏表提前返回。** 改为遍历相邻结构行并保存各自范围，损坏表只拒绝自身，不吞掉后续独立声明。
4. **双重解析与错误事务解释。** 删除重复解析和无用数学屏蔽代码；纠正仓储、library service、边界检查脚本的注释。“不能 async”是错误根因解释，实际保证是事务范围、请求等待和失败传播。没有改变事务行为来迎合这个错误解释。

复审的代码修改均在上述同类问题范围内；没有新增解析框架、替换生产协调器或向 app.js 增加业务算法。
