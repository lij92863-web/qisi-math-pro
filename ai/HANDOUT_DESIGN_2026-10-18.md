# 讲义功能设计（调研 + 设计草案）

日期：2026-10-18 · 目标用户：高中数学老师，自用，非程序员

## 一、同行是怎么做的（调研结论）

看三家现成产品后，老师端的操作流程**高度一致**，这不是巧合，是教师工作习惯：

1. **相濡以沫**（zhaoyimo.com）：选题（按章节/知识点/试卷）→ 加入试题篮（调顺序、改题量）→ 生成草稿（选讲义/试卷/分层作业模板）→ 一键编译导出 PDF/Word。主打 LaTeX 自动排版、A/B/C 分层作业、编译记录可追溯。
2. **PPmotion**：对话式出题 + 文档引擎，一键导出"出版级" Word/PDF，支持多模板切换、自动编题号分页页眉页脚。
3. **通用 quiz 生成器**（findutils）：浏览器内 LaTeX 渲染（`$...$`）、拖拽排序、可带答案页导出。

**共同点（要抄的）**：四步流程、试题篮、模板切换、PDF/Word 双导出、解析可开可关。
**共同坑（要避的）**：Word 导出后公式掉格式；模板好看但改不了；导出前看不到真实版式。

## 二、设计原则（按本项目一贯的底线）

1. **模板只管版式，绝不动题目内容。** 换模板不改一个字、不改一个公式。
2. **不猜。** 题号、分值、留白高度都来自老师显式设置；解析缺失就空着，不自动补。
3. **所见即所得。** 预览必须等于导出结果（同一套 HTML+CSS 渲染，打印 CSS 复用）。
4. **公式零乱码。** 一律走 KaTeX 渲染，导出前逐题校验，发现非法 LaTeX 就标红并**阻止导出**，而不是导出一份乱码讲义。

## 三、操作流程（建议四步，和同行一致，老师不用学）

1. **选题**：按章节 / 知识点 / 某次导入的试卷，勾选题目到"讲义篮"。
2. **编排**：拖拽调顺序；批量设置分值、留白、是否显示解析；支持 A/B/C 分层分组。
3. **选模板**：系统内置（讲义 / 试卷 / 分层作业 / 错题本）+ **"我的模板"**（老师自己另存的）。
4. **导出**：即时预览 → 导出 PDF（推荐）/ Word（兜底）/ 打印。

## 四、模板能改什么（不能改什么）

**能改**：字体（宋体/黑体/ Times）、正文字号、标题字号、行距、页边距、单双栏、题号格式（`1.` / `一、`）、题干与选项间距、作答留白高度、颜色（标题色、强调色、分割线色）、页眉页脚文字、是否带解析、解析是跟题还是集中放最后。
**不能改**：题号顺序、题干文字、选项内容、答案、公式源码。

## 五、公式保真怎么保证

- 存储：题目库里已经是 LaTeX（`$...$`），讲义直接复用，不二次转换。
- 渲染：KaTeX（项目已内置 vendor），预览与 PDF 同源。
- 门禁：导出前逐字段跑一遍校验（复用已有的"公式必须写成 LaTeX"检查），
  有问题的题**标红并阻止导出**，列出题号让老师自己改——宁可导不出，也不导出乱码。
- Word 导出：公式转成图片嵌入，确保 Word 里看得见（代价是不可编辑）；
  **优先推荐 PDF**，Word 作为"要二次编辑"时的兜底。

## 六、界面要点（待出视觉稿）

- 顶部四步进度条（选题 / 编排 / 模板 / 导出），老师随时知道自己在哪一步。
- 模板区用**卡片缩略图**（不是下拉框），一张卡一个版式，鼠标悬停看细节。
- 右侧常驻**实时预览**，改任何设置立刻看到效果。
- 编排区支持拖拽，每行右侧有"分值 / 留白 / 隐藏解析"三个小开关。
- 导出按钮两个：「导出 PDF（推荐）」「导出 Word（可再编辑）」，主次分明。

## 七、待老师拍板的三个问题

1. **导出以谁为主**：PDF（版式稳、公式漂亮、不可编辑）还是 Word（可改、公式会退化）？
2. **解析默认给不给**：教师版带解析、学生版不带，是不是要一键切换两套？
3. **模板要不要支持"照着一份现成讲义改"**：即允许导入一个 PDF/图片当版式参考（成本较高，可后做）。

## 八、技术落点（本项目现状）

- 预览/导出：浏览器内 HTML + KaTeX + 打印 CSS；PDF 用本地 Chromium 打印（本地服务已有 Playwright 依赖，或走浏览器自带打印）。
- 模板存储：作为一条 JSON 存进题库（表结构待定），"我的模板"可命名、可复制。
- 与现有模块的关系：只读 `questions` 表，**不写回题目内容**，讲义草稿单独一张表。
