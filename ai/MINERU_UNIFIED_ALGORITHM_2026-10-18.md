# MinerU 统一证据算法

## 根因与职责

故障共同来源是同一原文在多个消费者被再次解释，且模型引用检查与输出生成是两个互不约束的过程。修复数据流为：原始项 → 唯一规范化块 → 带绝对区间的候选分段 → 来源归属校验 → 字段投影。模型只能在已确定的题目范围内选择字段。预览和 HTTP 不再转换协议。

本轮不是新的生产入库路线。结构可信、内容核对、资产可持久化三个状态独立；未逐页核对的 OCR 文本不能因结构通过自动变成已验收内容。

## 不变量

1. 索引是单射：每个非空 ID 对应唯一块，重复输入不能构造索引。parent 与 origin 引用闭合；片段用半开区间 [start,end)，text 必须等于原文对应切片。
2. 分段是有序分割：所有片段串接严格等于输入字符串，正文与前导内容均保留；数学区域内字符不产生题号/选项候选。
3. 候选不是证明：题干内部行首编号、内部多小问头可能与解题步骤同形，应保留候选和歧义。题数 expected 只验证顺序，不消除歧义。支持材料内部有明确答案/解析标签或独立选项答案，才具备额外角色证据。
4. 章节重启需两段严格递增、题号序列完全一致且后段每个头有支持证据；不再依赖已见三题之类阈值。
5. 输出题号必须与显式 expected 或完整确定性题干序列一致。每个模型引用必须位于对应题号、对应角色的来源范围内。缺字段、错 phase、重复 ID、错序、缺号、未知引用、截断输入任一违反契约，不能输出答案或解析。
6. 原始答案声明形成集合。表格、头部、所有明确“故选”结论都保留来源；仅对严格 A–H 标签执行大小写/顺序标准化，其余原文精确比较，不做代数等价或语义推断。集合多值即冲突，不采取头优先/表优先/多数票。
7. 选项是原文区间：完整连续的 A..末标签序列且位于数学区域外，才能切分；前导片段返回题干或留在证据中，绝不丢弃。多标签共享原块时，不能复制整块充当多项；无法切分输出未解析状态。
8. 图片保留完整路径及来源身份，basename 仅可作显示名称，不能作解析键。

## 单一算法入口

- qisi-mineru-evidence：数学掩码、答案声明聚合、选项区间。纯函数不调用网络。
- qisi-paper-segmenter：发现/验证有序分段并产出来源注册表，确定性结果统一决定支持绑定。
- qisi-block-ownership：严格 schema → 复用分段来源范围 → 模型字段投影。单题公开入口也经过同一流程；不能绕过校验直接拼出可用支持材料。
- qisi-mineru-client 是 content_list 唯一转换口；预览复用它；HTTP 直接传递已定义的结果对象。

## 复杂度和验收

设 C 为字符数、B 为块数、R 为模型引用数、Q 为题数。掩码、候选扫描、字段投影 O(C)，索引/归属集合 O(B+R+Q)；章节候选若出现重复只验证第一个完整重启，不枚举所有分割组合。禁止全对全语义比较。

反例按算法性质生成：任意题号平移、数学标记包裹、重复/倒序/交换引用、跨文件同名、相同选项块、冲突声明、片段再分割。六份现存 ZIP 用于观察实际覆盖变化；若更严格算法揭示原来误称通过的歧义，如实列出，不放宽算法追求19/19。
