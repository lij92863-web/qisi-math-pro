# TEX题库讲义已知边界与恢复办法

## 1. 明确不支持

- 任意 Typst 源码编辑；
- Word 导出；
- 云同步、云编译和多人协作；
- 任意坐标的桌面出版式排版；
- 复杂不规则文字环绕；
- 二维码生成；
- AI 自动改写、总结或生成讲义。

这些边界用于保持本地、可验证、可迁移和学生版安全，不应通过在 `qisi-handout-app.js` 中增加临时分支绕过。

## 2. 公式

MiTeX 已覆盖常见高中数学公式，但未知宏包命令或不完整 LaTeX 仍可能失败。失败时系统必须显示内容块/字段/公式定位并阻止导出。

恢复步骤：

1. 根据错误面板定位内容块和公式；
2. 返回编辑器修正该公式；
3. 再次正式预览；
4. 不要把公式截图或原始错误文本静默塞入 PDF。

## 3. 图片与资源

讲义只接受本地拥有、类型受支持且可以挂载到虚拟文件系统的图片。源题图片插入讲义后会复制成讲义资产；源题被删除不应让现有讲义图片失效。

出现“资源缺失”时，应重新选择本地图片或重新从源题更新所选图片字段。不要直接修改 IndexedDB。

## 4. 保存与冲突

- 输入后顶部会依次显示“有未保存修改/正在保存/已保存到本地”。
- 两个页面同时编辑同一讲义时，乐观并发冲突会阻止后写覆盖。
- 应重新打开讲义，比较需要保留的版本，再执行恢复或复制。
- 版本恢复和删除必须通过正常 UI 确认。

## 5. 缓存与离线

首次正式编译必须从本地服务读取固定运行时资产；之后浏览器重启可使用版本匹配的本地缓存。升级后旧缓存会被清理。

若正式预览长期停在初始化：

1. 确认本地服务仍在运行；
2. 关闭正式预览后重试；
3. 刷新讲义页面；
4. 仍失败时保留控制台和编译诊断，不删除讲义数据；
5. 只有确认运行时版本升级异常时才清理该站点缓存。

## 6. 规模

H8 已实际生成 5、20、50 页样本。更大讲义没有被宣称为无限规模；图片数量、单图尺寸、公式复杂度和浏览器内存都会影响耗时。超大讲义应按章节拆分，避免一次嵌入大量原图。

## 7. 浏览器和打印

正式 PDF 是可交付结果。浏览器自带打印对话框可能受应用内浏览器的安全策略限制；这不等同于 PDF 生成失败。应先下载 PDF，再由 Edge/Chrome/PDF 阅读器打印。
