# TEX题库讲义制作使用指南

## 1. 进入与创建

1. 启动本地服务并打开 `main.html`。
2. 从顶部导航进入“讲义制作”。
3. 点击左侧“＋”新建讲义，修改讲义名称。
4. 通过左侧按钮加入标题、正文、提示框、图片或分页；也可以点击“从题库插入”加入正式题目。

讲义数据和图片都保存在当前浏览器的本地数据库中。题目插入讲义时会建立快照，之后在讲义内修改不会回写正式题库。

## 2. 编辑与排版

- 左侧大纲用于选择内容块和检查顺序。
- 中间区域用于直接编辑；文本输入会即时进入编辑状态，并在 500ms 空闲后自动保存。
- 每个内容块都可以上移、下移、复制或删除。
- 题目右侧检查器可分别设置内容、选项、图片、答案解析、标签、显示和源题更新。
- 批量设置只作用于明确勾选的题目块，并形成一次可撤销操作。
- “撤销/重做”用于编辑历史；“立即保存”后应看到“已保存到本地”再关闭页面。

## 3. 学生版与教师版

- 学生版在投影阶段物理移除答案、分析、解析和教师提示，不依赖 CSS 隐藏。
- 教师版可把答案、分析、解析放在题内、题后或文末。
- 文末答案、分析、解析按题目在讲义中的顺序编号；同一道题在三个区段使用同一题号。

正式交付前建议依次查看：

1. 学生版 HTML 快速预览；
2. 学生版正式 PDF；
3. 教师版 HTML 快速预览；
4. 教师版正式 PDF。

## 4. 正式 PDF

点击“正式 PDF 预览”后，系统才会按需加载本地 Typst、MiTeX、中文字体和 PDF.js。第一页生成后可以使用“上一页/下一页”逐页检查，再下载同一份 PDF 字节。

老师的电脑不需要另装 Typst、TeX、LibreOffice、Python、Java 或 Rust。讲义编译资源随 TEX题库本地分发；普通题库页面不会预先加载这些大文件。

## 5. 建议的一线教师检查顺序

1. 题目是否完整，题号和选项是否对应；
2. 公式、向量、分式、根式和上下标是否清楚；
3. 图片是否属于当前题、位置是否正确；
4. 分页前后是否出现孤立标题或大块空白；
5. 学生版是否完全没有答案、分析或解析；
6. 教师版文末答案和解析题号是否一致；
7. 下载后再打开 PDF 抽查第一页、跨页处和答案页。

## 6. 备份

讲义属于本地数据。更换浏览器配置、清除网站数据或换电脑前，应先使用系统的数据导出/备份功能。讲义图片是讲义自有 Blob 资产，不能只复制某一段页面 HTML 作为备份。
