## 1. 边界

本阶段只补齐讲义最终证据、运行指标、产品交互缺陷、文档和回归。没有修改 `app.js`、DOCX/PDF 识别、答案对齐、真实题库数据或 AI/OCR 链。

## 2. 本阶段真实操作发现并修复的问题

1. 正式题库使用数字毫秒时间戳时，插入讲义被误判为非法时间。现在统一接受 `Date`、ISO、10 位秒、13 位毫秒和数值毫秒；其它格式继续失败关闭。
2. 标题、正文和提示框只监听 `change`，快速预览/保存可能丢失刚输入的内容。现在文本走 `input`，复用已有 500ms 自动保存和同字段撤销合并，不增加每字一条历史。
3. 文末只有一道题时，答案编号为 1、解析却错误变成 2。现在先建立讲义题目顺序映射，再按答案/分析/解析分组，同一道题始终使用同一题号。
4. 左侧动态内容块按钮没有显式可访问名称。现在按“序号 + 内容块名称”提供动态 `aria-label`。

上述修复都有自动回归，并在正常 UI 中再次保存、刷新、正式编译和翻页确认。

## 3. 一线教师产品实操

在隔离的 `127.0.0.1:3018` 本地站点通过正常 UI 完成：

```text
新题录入 → 高二/单选/中等 → 录入含公式题目/选项/答案/解析
→ 保存入库 → 题库检索/筛选 → 展开解析 → 选题
→ 智能组卷台 → 切换无框/带框、学生/教师、三种答案位置
→ 讲义制作 → 新建 → 标题/正文/提示/分页
→ 从正式题库插题 → 上移 → 批量设置 → 撤销/重做
→ 保存 → 刷新 → 学生/教师快速预览
→ 正式 PDF → 上一页/下一页 → 逐页查看
```

结果：

- 搜索、筛选、解析展开、选题和组卷状态联动正确；
- 插题不会回写源题，数字时间戳题目可插入；
- 批量设置只影响勾选题目，撤销/重做和刷新持久化正确；
- 学生正式 PDF 无答案，教师正式 PDF 答案与解析编号一致；
- 实操页面控制台无错误；
- 应用内浏览器阻止受保护的系统打印弹窗，因此没有绕过安全策略；打印链由隔离浏览器回归和实际 PDF 文件继续验收。

讲义页面当前有 67 个 `@click` 绑定、65 个不同表达式。静态契约确保每个调用都解析到真实方法、每个按钮有可访问名称；H3/H5/H6/H7 浏览器套件与本阶段实操覆盖创建、编辑、移动、复制、删除、撤销、重做、图片、题库插入、搜索、批量、源题冲突、版本恢复、学生/教师预览、正式编译、取消、翻页、下载和清理等动作族。
